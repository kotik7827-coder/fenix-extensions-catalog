# Разбор содержимого сайта

Используй только текст, который предоставил пользователь или который получен через разрешённый инструмент. Не выдумывай сведения о компании, товарах, ценах и результатах клиентов.

Сначала определи назначение страницы и её целевую аудиторию. Затем дай результат по-русски:

1. **Что уже работает** — до трёх конкретных сильных мест.
2. **Что мешает результату** — неясные формулировки, пробелы в структуре, слабые аргументы и призывы к действию.
3. **Приоритетные правки** — нумерованный список от самого важного к второстепенному.
4. **Предлагаемые заголовки** — основной заголовок страницы, SEO title до 60 символов и meta description до 160 символов, если хватает исходных данных.
5. **Переписанный фрагмент** — только один наиболее важный блок, без выдуманных фактов.

Если исходного текста нет, попроси вставить текст страницы. Не заявляй, что просмотрел сайт, если его содержимое не было получено.
